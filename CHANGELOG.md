## [1.2.1] — 2026-05-23

### Changed
- Уплощён список триггер-фраз в README — все 15 фраз в одном списке без градации «основные / косвенные»
- Убрано дублирование пути установки в разделе Claude.ai
- Упрощено форматирование примеров модификаторов (убраны лишние blockquote)
- Пример выхода в разделе 4 привязан к реальному debug-чату по расхождению в Excel-отчёте из Bitrix24
- Mixed-режим: добавлено объяснение эвристического определения смены темы
- Архитектурное объяснение «почему запрос не вшивается в блок» вынесено из списка в отдельный абзац
- История версий в README сокращена до 1–2 ключевых улучшений на запись

## [1.2.0] — 2026-05-23

### Changed
- Переработан `description`-триггер в `SKILL.md`: акцент на **session migration** вместо summarization — модель теперь чётче разграничивает хэндоф и суммаризацию кода/PR/документов
- Уточнена граница `skip`: явно запрещено срабатывание для клиентских саммари, memory-сохранений без new-chat intent, суммаризации внешних материалов

### Added
- Расширен список триггер-фраз в `description`: добавлены русскоязычные варианты (`суммаризируй чат`, `суммаризируй диалог`, `продолжим в новом чате` и др.)
- Добавлен `.gitignore` — папка `evals/` исключена из репозитория

### Tested
- Полное eval-тестирование через skill-creator framework: 5 тест-кейсов, 10 запусков (with skill + baseline)
- Результат: **100% pass rate** со скиллом vs **73%** без него (+27% delta)
- Запущен description optimizer: 40 trigger-eval queries, 5 итераций

## [1.1.0] — 2026-05-22

### Added
- Секция «Когда отказаться от генерации»: отказ на пустом/коротком чате одной строкой без блока
- Обработка рекурсивного handoff: если чат начался со вставленного блока — старый блок используется как контекст, но не цитируется целиком; выжимка пересобирается от текущего состояния
- Целевой ориентир длины выдачи: 50–150 строк
- Примеры выдачи для компактного и mixed-режимов
- Контр-примеры для секции «Договорённости этого чата»

### Changed
- Триггер-фразы продублированы в тело скилла (были только в `description`)
- «Молча» заменено на «без промежуточных сообщений» для точности

---

## [1.0.0] — 2026-05-21

### Added
- Initial release
- Дефолтный, компактный и расширенный режимы генерации
- Mixed-режим для чатов с несколькими несвязанными темами
- Шаблон fenced markdown-блока с секциями: TL;DR, Запомни, О чём был чат, Главное, Решения и почему, Текущее состояние, Артефакты, Источники, Договорённости, Открытые вопросы
- Строка-инструкция перед блоком («Прочитай молча. Ответь одним словом — „принял"»)
