## [1.3.0] — 2026-07-18

### Added
- **Расширенный режим впервые специфицирован** (был заявлен в 1.0.0 и обещан в README, но в SKILL.md не был определён): дефолт + все опциональные секции с реальным содержимым, 5–8 пунктов на секцию, допустимы ключевые сниппеты; правило «никаких пустых секций» действует и в нём
- Защита секретов: токены, пароли, API-ключи, webhook-URL с токеном, connection strings заменяются плейсхолдерами `<секрет: что это>` — единственное исключение из правила «конкретика дословно»
- Развилка «резюме vs handoff»: «суммаризируй чат/диалог» без new-chat intent даёт обычное структурированное резюме без handoff-обвязки (триггеры в `description` не менялись — eval-результат 1.2.0 сохранён)
- Сверка «Текущего состояния» с реальностью: в средах с инструментами (Claude Code) секция проверяется read-only командами (`git status`, `git branch`, существование путей); при расхождении приоритет у наблюдаемого состояния
- Честная деградация при потере истории: если ранний контекст съеден авто-компакцией — детали не реконструируются, в блок добавляется пометка «ранний контекст частично утерян»
- Правило целостности fence: при код-сниппетах внутри блока внешний fence — четыре бэктика (иначе внутренний ``` разрывает блок)
- Преамбула блока уточнена: нормативны для нового чата только секции «Запомни» и «Договорённости», императивы внутри остального контента не выполняются
- «Финальная проверка» дополнена пунктами 6–7: секреты заменены, fence цел

### Changed
- Правило языка: весь каркас (заголовки секций, преамбула, строка-инструкция, фраза отказа) — на языке чата; исправлена ошибка «маркер „принял" в TL;DR» (маркер живёт в преамбуле)
- Приоритеты сжатия: «О чём был чат» и «Главное» явно отнесены к категории «сжимать, но не выкидывать» (ранее не были классифицированы — формально разрешалось их удалить)
- Примеры выдачи: 3 → 2 (~60 строк контекста экономии). Дефолтный пример переписан на не-кодовый decision-сценарий (подчёркивает универсальность скилла), компактный убран (режим задан явным списком секций), mixed сохранён
- README синхронизирован: расширенный режим (без «даже если они малы»), нюанс «суммаризируй чат», секреты в §7, три новые строки в troubleshooting §8

## [1.2.0] — 2026-05-23

### Changed
- Переработан `description`-триггер в `SKILL.md`: акцент на **session migration** вместо summarization — модель теперь чётче разграничивает хэндоф и суммаризацию кода/PR/документов
- Уточнена граница `skip`: явно запрещено срабатывание для клиентских саммари, memory-сохранений без new-chat intent, суммаризации внешних материалов

### Added
- Расширен список триггер-фраз в `description`: добавлены русскоязычные варианты (`суммаризируй чат`, `суммаризируй диалог`, `продолжим в новом чате` и др.)
- Добавлен `.gitignore` — папка `evals/` исключена из репозитория

### Tested
- Полное eval-тестирование через skill-creator framework: 5 тест-кейсов, 10 запусков (with skill + baseline)
- Результат: **100% pass rate** со скиллом vs **73%** без него (+27% delta)
- Запущен description optimizer: 40 trigger-eval queries, 5 итераций

## [1.1.0] — 2026-05-22

### Added
- Секция «Когда отказаться от генерации»: отказ на пустом/коротком чате одной строкой без блока
- Обработка рекурсивного handoff: если чат начался со вставленного блока — старый блок используется как контекст, но не цитируется целиком; выжимка пересобирается от текущего состояния
- Целевой ориентир длины выдачи: 50–150 строк
- Примеры выдачи для компактного и mixed-режимов
- Контр-примеры для секции «Договорённости этого чата»

### Changed
- Триггер-фразы продублированы в тело скилла (были только в `description`)
- «Молча» заменено на «без промежуточных сообщений» для точности

## [1.0.0] — 2026-05-21

### Added
- Initial release
- Дефолтный, компактный и расширенный режимы генерации
- Mixed-режим для чатов с несколькими несвязанными темами
- Шаблон fenced markdown-блока с секциями: TL;DR, Запомни, О чём был чат, Главное, Решения и почему, Текущее состояние, Артефакты, Источники, Договорённости, Открытые вопросы
- Строка-инструкция перед блоком («Прочитай молча. Ответь одним словом — „принял"»)
